# Project Overview

SmartBus is an intelligent transportation application designed to improve the public transportation experience by integrating **real-time bus tracking, smart route planning, and digital ticket payments**.

Urban transportation systems often lack convenient digital tools for passengers to track buses or plan trips efficiently. SmartBus addresses this challenge by providing a platform where users can:

- search bus routes
- track buses in real time
- find optimal travel paths
- purchase digital tickets
- view nearby stations through interactive maps

The project focuses on **improving accessibility, real-time transportation visibility, and user experience in urban mobility**.

# Key Features

## Real-time Bus Tracking

Users can track bus locations in real time through live transportation data integrated with map visualization.

## Smart Route Planning

The system calculates optimal travel routes between locations to help users reach their destination efficiently.

## Digital Ticket Payment

Passengers can purchase and manage **digital bus tickets** directly within the application.

## Discount Support

The platform supports **discount policies for students and senior citizens**.

## Google Maps Integration

Interactive maps allow users to explore:

- bus routes
- bus stations
- nearby stops
- real-time transportation data

# System Architecture

The system follows a modern **web-based layered architecture**.
Frontend (React / React Native)
↓
REST API
↓
Backend (.NET / C#)
↓
Database

External integrations include:

- Google Maps API → route visualization and map services
- PayOS → digital ticket payment processing
- Cloudinary → image and asset storage
